Prototipo: traduzione nel browser

Test sperimentale delle API di traduzione locale del browser. Non utilizza servizi remoti per inviare il testo. Il browser può scaricare un modello linguistico alla prima esecuzione.

Verifica delle capacità del browser in corso…

Questo test usa la Translator API sperimentale del browser, non ancora Bergamot incorporato. Nessun testo viene trasmesso da questa pagina a un servizio di traduzione. La disponibilità dipende dal browser e dal sistema operativo.
