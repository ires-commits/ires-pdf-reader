# IRES PDF Reader 1.2.0

Lettore PDF WordPress indipendente. Funzionalità: shortcode `[ires_pdf_reader url="https://example.org/documento.pdf"]`, overlay, pagina dedicata e integrazione automatica opzionale per il CPT `pubblicazione`.

## Sicurezza
Per impostazione predefinita sono ammessi PDF serviti dallo stesso host del sito. Altri host richiedono configurazione esplicita del filtro `ires_pdf_reader_allowed_hosts`.

## Aggiornamenti
Il plugin verifica le release pubbliche del repository `ires-commits/ires-pdf-reader`. Per ricevere gli aggiornamenti, installare il plugin nella directory `ires-pdf-reader` e abilitare gli aggiornamenti automatici in WordPress.

## Verifiche
Eseguire i test su un sito staging prima dell'uso in produzione.
