# IRES PDF Reader

Plugin WordPress autonomo per consultare PDF in overlay e in una pagina dedicata, con integrazione opzionale con le pubblicazioni IRES.

## Struttura
- `ires-pdf-reader/`: codice del plugin
- `.github/workflows/release.yml`: costruzione automatica dello ZIP quando viene pubblicato un tag `vX.Y.Z`
- `CHANGELOG.md`: storico delle modifiche

## Installazione
Le release includeranno il file `ires-pdf-reader.zip`. Prima di usare il plugin sul sito istituzionale, provarlo in staging.

## Aggiornamenti automatici
Il plugin legge la release pubblica più recente da GitHub. WordPress può installarla automaticamente se gli aggiornamenti automatici sono abilitati.

## Stato
Sorgenti della versione 1.2.0 pubblicati. Prima release non ancora creata: sono necessari controlli della pipeline e test funzionali.
